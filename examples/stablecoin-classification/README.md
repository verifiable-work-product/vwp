# Example: Stablecoin classification (synthetic)

A demo VWP package classifying a fictional treasury's stablecoin holdings across custodians: each holding's classification rests on a linked judgment and evidenced redemption terms, and the same token from the same issuer is classified the same way everywhere.

**All data is synthetic. This example is not accounting, legal or tax advice.**

What it demonstrates:

- The `vwp-digital-assets-stablecoin` **holdings register** at `facts/stablecoin-holdings.json`.
- `stablecoin.classification.judgmentLinked`, `stablecoin.redemption.evidence` and `stablecoin.classification.consistent`.
- `stablecoin.classification.cashEquivalentChallenged`: any cash-equivalent classification of a token with no maturity is flagged `reviewRequired` for a human disposition.

Generated by the Go SDK's fixture generator (`cd sdk/go && go run fixturegen/main.go`),
which refuses to write a package that does not verify clean; object ids carry the
section prefixes (`s1_` … `s5_`) of the authoring template.
