# Example: Digital asset lending (synthetic)

A demo VWP package for a fictional crypto loan: in-kind interest accrued per window from the terms fact, collateral coverage with margin shortfall and the unsecured portion, and a derecognition conclusion (ASC 860-10-40-5) recorded as a claim with a linked judgment.

**All data is synthetic. This example is not accounting, legal or tax advice.**

What it demonstrates:

- `digitalAssetLoanInterestAccrual` and `collateralCoverage` calculations that recompute from the facts they cite (`lending.accrual.recompute`, `lending.collateral.recompute`).
- `lending.derecognition.claimJudged`: whether control of the lent asset passed is a judged claim, never arithmetic.
- The required `interest_accrual` accounting schedule, one entry per accrual window at the fee's fair value.

Generated by the Go SDK's fixture generator (`cd sdk/go && go run fixturegen/main.go`),
which refuses to write a package that does not verify clean; object ids carry the
section prefixes (`s1_` … `s5_`) of the authoring template.
