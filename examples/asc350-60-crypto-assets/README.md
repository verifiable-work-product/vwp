# Example: ASC 350-60 crypto assets (synthetic)

A demo VWP package for a fictional treasury holding BTC, ETH and a wrapped token for the quarter ended 2026-06-30: the ASC 350-60 scope conclusion per asset, the per-asset roll-forward with the period's remeasurement gains and losses, the significant-holdings disclosure table, and the executable remeasurement schedule.

**All data is synthetic. This example is not accounting, legal or tax advice.**

What it demonstrates:

- The `vwp-accounting-asc350-60` **scope register** at `facts/crypto-assets.json`: the six ASC 350-60-15-1 criteria per asset, with the wrapped token routed out of scope by a linked judgment.
- `cryptoAssetRollForward` and `significantCryptoHoldings` calculations that tie line by line and to each other (`asc35060.rollForward.tieOut`, `asc35060.significantHoldings.tiesToRollForward`).
- The required `calculations/accounting-schedule.json` (`fair_value_remeasurement`) proven against the roll-forward by `asc35060.accountingSchedule.tieOut`.

Generated by the Go SDK's fixture generator (`cd sdk/go && go run fixturegen/main.go`),
which refuses to write a package that does not verify clean; object ids carry the
section prefixes (`s1_` … `s5_`) of the authoring template.
