# Example: Cost basis lot relief (synthetic)

A demo VWP package relieving fictional lots on disposal under FIFO: units conserved from the lot population through every relief, basis and realized gain/loss recomputed from the lots, and the Rev. Proc. 2024-28 wallet-by-wallet allocation of unused basis as of 2025-01-01.

**All data is synthetic. This example is not accounting, legal or tax advice.**

What it demonstrates:

- A `lotRelief` calculation checked for unit conservation, recompute and method order (`costBasis.lotRelief.*`).
- A `walletBasisAllocation` tied to the pre-2025 lot population (`costBasis.walletAllocation.eligibility`).
- The required `realized_gain_loss` accounting schedule: proceeds in, cost basis out, the difference as gain or loss, per disposal.

Generated by the Go SDK's fixture generator (`cd sdk/go && go run fixturegen/main.go`),
which refuses to write a package that does not verify clean; object ids carry the
section prefixes (`s1_` … `s5_`) of the authoring template.
