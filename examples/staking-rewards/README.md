# Example: Staking rewards (synthetic)

A demo VWP package recognizing staking rewards on a fictional validator arrangement for one quarter: each reward at units × price on its recognition date, reconciled to the receipts observed on chain, with the income accounting schedule.

**All data is synthetic. This example is not accounting, legal or tax advice.**

What it demonstrates:

- A `stakingRewardsSchedule` calculation whose fair values recompute (`staking.rewards.recompute`) and whose prices are evidenced as of the right date (`staking.rewards.pricingEvidence`).
- Recognized units reconciled to chain-observed receipts through unreceived opening/closing balances (`staking.rewards.chainTieOut`).
- The required `staking_rewards` accounting schedule: income on recognition, receivable until receipt.

Generated by the Go SDK's fixture generator (`cd sdk/go && go run fixturegen/main.go`),
which refuses to write a package that does not verify clean; object ids carry the
section prefixes (`s1_` … `s5_`) of the authoring template.
